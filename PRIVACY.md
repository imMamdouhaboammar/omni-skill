# Privacy Policy

**OmniSkill** is an open-source, local-first Skill Engineering Toolkit and Cross-Host Plugin.

- **No Data Harvesting**: OmniSkill operates entirely on your local machine or within your active agent runtime. It does not run a hosted data-collection backend or telemetry service.
- **Local Capability Execution**: Operations (such as file reads, AST parsing, static analysis, and eval testing) are performed using host-native capabilities governed by your permissions.
- **Credential Protection**: OmniSkill includes static checks that can flag recognizable credentials in scanned resources. These checks are not exhaustive; review scan coverage and findings before sharing an artifact.
