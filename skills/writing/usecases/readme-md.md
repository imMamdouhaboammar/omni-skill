# Drafting High-Conversion Project README.md

Structure for open-source repositories and packages.

1. **One-Sentence Value Proposition**: Immediately answer what the project is, who it is for, and why it is superior to alternatives.
2. **Immediate Installation Command**: Provide the 1-liner install snippet (e.g. `npx skills add <repo>` or `bun install -g <pkg>`) before long prose.
3. **Architecture / DAG Diagram**: Use a clean Mermaid chart or ASCII block diagram to show system flow.
4. **Primary CLI Commands**: Show copy-pasteable CLI commands with concrete arguments.
5. **Quality & Verification**: State automated test commands (`bun test`) and release badges.
6. **Zero Speculative Documentation**: Ground all instructions in verified local reality.
